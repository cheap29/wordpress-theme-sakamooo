# sakamooo - WordPress テーマ

> 和風ポップをテーマにした、日本語ブログ・ポートフォリオ・コーポレートサイト向け WordPress テーマです。

カタログ風グリッド・スティッキーナビ・Hero セクションを標準装備し、カスタマイザーから主要レイアウトをコードなしで設定できます。

![sakamooo スクリーンショット](screenshot.png)

---

## 特徴

- **和風ポップな配色** — 伝統的な和のカラー + ビビッドアクセントの組み合わせ
- **カタログ風グリッド** — 記事をカード形式でゆったり並べる UI
- **Hero セクション** — 見出しテキスト・縦横位置・フォントサイズをカスタマイザーで設定
- **固定ページブロック** — 最新記事の下に最大3つの固定ページを表示
- **Sticky サブナビ** — スクロール追従ナビゲーション
- **パンくずナビ** — アクセシビリティ対応
- **レスポンシブ** — CSS のみでモバイル/PC を最適化

## インストール

**方法 A: ZIP アップロード**
1. このリポジトリを ZIP でダウンロード
2. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**
3. ZIP を選択して有効化

**方法 B: 直接配置**
1. `sakamooo/` フォルダを `wp-content/themes/` 配下に配置
2. 管理画面 → **外観 → テーマ** から有効化

---

## カスタマイズ

**外観 → カスタマイズ** から以下を設定できます（コード不要）:

| 設定項目 | 内容 |
|---|---|
| Hero | 見出しの表示/非表示・テキスト・縦横位置・フォントサイズ |
| グリッドセクション | セクションタイトル・表示カテゴリー |
| 固定ページブロック | 最新記事下に表示する固定ページ（最大3つ） |

## テンプレート構造

```
sakamooo/
├── style.css            # テーマ定義・メイン CSS
├── functions.php        # テーマ設定・カスタマイザー登録
├── header.php           # ヘッダー・ナビゲーション
├── index.php            # トップページ・グリッド表示
├── single.php           # 単一記事テンプレート
├── page.php             # 固定ページテンプレート
├── sidebar.php          # サイドバー
├── footer.php           # フッター
├── assets/              # CSS・JS・画像
└── screenshot.png       # テーマプレビュー画像
```
