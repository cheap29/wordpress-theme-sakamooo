# Wordpress テンプレート sakamooo

**sakamooo** は和風ポップをテーマにしたシンプルでカスタマイズ性の高い WordPress テーマです。  
M PLUS 1p をベースにしたモダンなタイポグラフィ、カタログ風グリッド、ヘッダー／サブナビのスティッキーなど、ブログやコーポレートサイトにも使いやすい設計です。

---

## 🎨 主な特徴

- **和風ポップな配色**: 伝統的な和のカラー + ビビッドアクセント  
- **レスポンシブ対応**: モバイル⇄PC の切り替えを CSS のみで最適化  
- **Sticky サブナビ**: スクロールしても追従するナビゲーション  
- **カスタマイザー連携**  
  - Hero 見出しの表示/非表示・位置・サイズ  
  - 最新記事下に最大3つの固定ページを表示  
- **パンくずナビ**: 可読性とアクセシビリティを両立  
- **グリッド＆カード表示**: カタログ風にゆったり並べる UI  
- **テーマオプション**: 外観 → カスタマイズ から各種設定が可能

## 🚀 インストール

1. このリポジトリをクローンまたはダウンロード  
2. WordPress 管理画面 → **外観 → テーマ → 新規追加 → テーマのアップロード**  
3. `sakamooo.zip` をアップロードして有効化  

または、テーマフォルダ `sakamooo/` を直接 `wp-content/themes/` 配下に配置して有効化してください。

---

## ⚙️ カスタマイズ／設定

**外観 → カスタマイズ** で以下を設定できます:

- **Hero 設定**  
  - 見出しの表示/非表示  
  - 見出しテキスト  
  - 縦位置 / 横位置 / フォントサイズ  

- **グリッドセクション**  
  - セクションタイトル  
  - 表示するカテゴリー（最新記事を固定ページとしても利用可）  

- **固定ページブロック**  
  - 最大 3 ページの選択 → 最新記事下に順番に表示

## 📁 テンプレート構造

```
sakamooo/
├── assets/          # 静的ファイル
├── template-parts/  # テンプレートパーツ
├── functions.php    # テーマの主な設定
├── header.php       # ヘッダー
├── index.php        # メインテンプレート
├── page.php         # 固定ページテンプレート
├── single.php       # 単一記事テンプレート
├── footer.php       # フッター
└── style.css        # CSS
```
